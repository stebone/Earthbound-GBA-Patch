# Earthbound-GBA-Patch
Mother 1+2 to Earthbound GBA
This is a patch of Mother 1+2 GBA (Japan)
Ive combined Jeffman's 2022 translation patch of Mother 2 and ShadowOne333's Mother 1+2 autoboot to Mother 2 patch
With the combiation of both patches it boots straight into Mother 2 and changes the title screen to Earthbound very simple hack to turn it into a port of SNES version
I dont want to take any credit as credit belongs to both of the developers that created both patches I simply wanted to make a westernized port of Mother 2 for the GBA
